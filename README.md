# ТРЕКОПЁС

**ТРЕКОПЁС** — веб-приложение и мобильные приложения для генерации музыки с помощью искусственного интеллекта. Позволяет создавать персонализированные музыкальные треки различными способами: по сценарию, фотографии, тексту, артисту или ссылке на профиль.

## 🎵 О приложении

ТРЕКОПЁС — это платформа для создания уникальной музыки с использованием технологий искусственного интеллекта. Приложение предлагает несколько способов генерации треков, настраиваемые параметры создания, систему подписок и полнофункциональный музыкальный плеер.

### Основные возможности

- **Генерация музыки по сценарию** — выбор сценария и заполнение анкеты для создания персонализированной песни
- **Генерация по фотографии** — создание трека на основе загруженного или сделанного фото (распознавание настроения, цветовой палитры и элементов изображения)
- **Генерация по ссылке** — анализ профиля ВКонтакте и создание трека на основе полученной информации
- **Генерация по артисту/стилю** — создание музыки в стиле выбранного артиста с настройкой параметров
- **Быстрая генерация по тексту** — создание трека из текстового описания с поддержкой голосового ввода
- **Музыкальный плеер** — полнофункциональный аудиоплеер с поддержкой плейлистов, переключения треков и управления воспроизведением
- **Система подписок и тарифов** — различные уровни доступа к функционалу приложения
- **Профиль пользователя** — управление балансом, историей генераций и платежей
- **Реферальная программа** — возможность приглашать друзей и получать бонусы
- **Интеграция с Telegram WebApp** — нативная работа в Telegram мини-приложении

### Управление состоянием

Приложение использует гибридный подход к управлению состоянием:

- **TanStack Store** — для клиентского состояния (черновики генераций, состояние плеера, UI состояние)
- **TanStack Query** — для серверного состояния (списки треков, данные пользователя, платежи)
- **LocalStorage/SessionStorage** — для персистентности данных (настройки, состояние плеера)

### Маршрутизация

Маршрутизация реализована на базе **TanStack Router** с файловым роутингом:

- `/` — главная страница (редирект на `/welcome` или `/generate`)
- `/welcome` — экран приветствия для новых пользователей
- `/generate` — главный экран выбора типа генерации
- `/chat` — чат с ассистентом
- `/profile` — профиль пользователя
- `/subscription` — оформление подписки
- `/tarrifs` — выбор тарифа
- `/referral` — реферальная программа
- `/question` — вопросы для сценария генерации

## 🎯 Основной функционал

### Генерация треков

#### 1. Генерация по сценарию (`scenario`)
Пользователь выбирает сценарий (поздравление, мотивация и т.д.) и заполняет анкету с вопросами. На основе ответов ИИ создает персонализированный трек.

**Возможности:**
- Выбор категории и целевой аудитории
- Заполнение вопросов анкеты
- Выбор референсного артиста
- Настройка параметров (темп, настроение, голос, стиль)

#### 2. Генерация по фотографии (`photo`)
Загрузка фото или снимок через камеру устройства. ИИ анализирует изображение и создает трек на основе цветовой палитры, настроения и элементов.

**Возможности:**
- Загрузка фото с устройства
- Съемка через камеру (фронтальная/задняя)
- Настройка параметров генерации
- Добавление текстового описания (опционально)

#### 3. Генерация по ссылке (`link`)
Ввод ссылки на профиль ВКонтакте. Система анализирует профиль и создает трек на основе полученной информации.

#### 4. Генерация по артисту/стилю (`style`)
Выбор артиста из каталога и создание трека в его стиле с дополнительными параметрами.

**Возможности:**
- Поиск и выбор артиста
- Настройка параметров (темп, настроение, голос)
- Генерация промпта на основе выбранного артиста

#### 5. Быстрая генерация по тексту (`text`)
Быстрое создание трека на основе текстового описания.

**Возможности:**
- Ввод текстового описания
- Голосовой ввод через распознавание речи
- Быстрый запуск генерации для PRO пользователей

### Параметры генерации

Все типы генерации (кроме быстрой) поддерживают настройку параметров:

- **Темп (Tempo)** — от 60 до 180 BPM с визуальными индикаторами (медленный, средний, быстрый)
- **Настроение (Mood)** — выбор из доступных настроений
- **Стиль (Style)** — выбор музыкального стиля
- **Голос (Voice)** — выбор голоса (мужской, женский, оба)

### Музыкальный плеер

Полнофункциональный аудиоплеер с поддержкой:

- Воспроизведение/пауза треков
- Переключение между треками (предыдущий/следующий)
- Управление прогрессом воспроизведения
- Отображение обложки и информации о треке
- Плейлисты и очереди воспроизведения
- Горячие клавиши (Space, стрелки, N/P для навигации)
- Сохранение позиции воспроизведения в sessionStorage
- Телеметрия прослушивания

### Система подписок

#### Тарифы (разовые платежи)
- **TRACK** (250 ₽) — 1 генерация, базовый функционал
- **PRO** (1 000 ₽) — 10 PRO-треков, расширенные возможности
- **ULTRA** (5 000 ₽) — 25 PRO-треков, полный доступ

#### Подписки (ежемесячные)
- **20 PRO-треков** (990 ₽/мес) — базовые PRO функции, бонус 48 ч на дубли
- **1 Premium + 50 PRO** (4 990 ₽/мес) — премиум трек с менеджером (5 итераций), 50 PRO генераций, обложки и анимации

**Особенности подписок:**
- Бонус 48 часов — вторая версия каждого трека бесплатно в течение 48 часов после заказа
- Гибкая система — оплата только за факт запуска генерации (1 трек = 1 генерация)

### Система платежей

Интеграция с платежными системами:
- **Робокасса** — основной платежный провайдер
- Поддержка карт Visa, Mastercard, МИР
- Обработка платежей через Webhook API
- История платежей в профиле пользователя

## 🚀 Запуск и разработка

### Требования
- Node.js 18+ 
- npm или yarn

```bash
npm install
```

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173` (или другой порт, если 5173 занят)

```bash
npm run preview
```
